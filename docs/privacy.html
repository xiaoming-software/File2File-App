File2File 隐私政策

更新日期：2026-10-26

File2File（「本应用」）由开发者 Mingding Li 提供。我们重视你的隐私。本政策说明应用如何处理信息。

1. 我们收集哪些信息

  • 账号与连接凭证：你输入的 webrpc Token、密码、认证口令等，仅用于建立点对点连接，保存在本机（含系统安全存储），不会上传到本应用开发者的自有服务器作为内容托管。
  • 设备权限：在你授权后，可能访问相机（扫码登录）、麦克风（语音通话）、相册/文件（收发媒体与文件）、本地网络（发现与连接附近设备）。
  • 诊断信息：若你通过 App Store 选择分享，Apple 可能向开发者提供崩溃与使用分析；除此之外本应用不主动采集广告标识或行为画像。

2. 文件与消息如何传输

聊天消息与文件通过 webrpc 加密通道在设备之间点对点传输；个人网盘功能连接的是你自己运行的 mywebdisk 服务，文件存放在你指定的磁盘目录。本应用开发者不托管你的聊天内容或网盘文件。

连接协调可能使用 webrpc 公共服务（见 webrpc.cn），其数据处理以该服务自身政策为准。

3. 信息共享

我们不会出售你的个人信息。仅在下列情况可能涉及第三方：提供连接所必需的 webrpc 服务、遵守法律法规、或保护用户与公众安全。

4. 数据保留与删除

本地会话记录、缓存与凭证由你在本机管理；卸载应用或清除应用数据即可删除本机相关数据。网盘服务器上的文件由你自行管理。

5. 儿童隐私

本应用不以 13 岁以下儿童为对象。

6. 联系我们

隐私相关问题请通过 GitHub Issues 联系：File2File-App Issues，或发送至你在 App Store Connect 中登记的联系邮箱。
